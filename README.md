# 💰 赚钱资讯站

自动收集全网赚钱、副业、商机相关资讯，每日更新，部署在 GitHub Pages。

## 🎯 功能

- 📡 自动爬取多平台赚钱相关资讯
- 🏷️ 按分类（副业/创业/投资/电商/AI）筛选
- 🔍 全文搜索
- 📱 响应式设计，支持移动端
- ⏰ 每日凌晨自动更新（GitHub Actions）

## 🏗️ 技术栈

- 前端：原生 HTML/CSS/JS（无框架，零依赖）
- 爬虫：Python + requests + BeautifulSoup
- 自动化：GitHub Actions
- 部署：GitHub Pages

## 🚀 如何部署

1. Fork 本仓库
2. 开启 GitHub Pages（Settings → Pages → Source: main branch）
3. 等待首次 Actions 运行完成
4. 访问 `https://你的用户名.github.io/money-news`

## ✨ 数据来源

- 知乎（副业/创业话题）
- 小红书（赚钱/带货话题）
- 36氪（创业/商业）
- 少数派（工具/效率/赚钱）
- 雪球（投资理财）

## 📝 自定义

修改 `articles.json` 手动添加内容，或在 GitHub Actions 中配置爬虫。
